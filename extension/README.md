# TradingAI Signal Hub

Brave использует Chromium, поэтому расширение ставится как обычное Manifest V3: откройте `brave://extensions`, включите режим разработчика и выберите **Load unpacked** → папку `extension`.

Перед запуском сервера добавьте в `.env` случайный секрет: `EXTENSION_API_TOKEN=...`. В popup укажите адрес сервера, этот токен и значение `OWNER_ID` как Telegram user ID.

Для анализа снимка добавьте `OPENROUTER_API_KEY=...`; при необходимости настройте `OPENROUTER_VISION_MODEL`. Ключ остаётся на сервере и никогда не попадает в расширение. Ведущий видимый снимок вкладки отправляется только после нажатия «Сделать снимок и проанализировать».

Архив берёт только строки `trade_signals` со статусом `analyzed`. Кнопка «Сохранить в базу» в парсере намеренно отключена по требованию: она не передаёт содержимое страницы.

Для выбора страницы требуется разрешение `debugger`: оно нужно только чтобы прочитать виртуальное DOM-дерево через Chrome DevTools Protocol (`DOM.enable`, `DOM.getDocument`, `DOM.describeNode`). Сам выбор блока выполняется в content script на текущей вкладке.
